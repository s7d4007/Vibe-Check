# Vibe Check

A fun, browser-based personality quiz that helps you discover your unique vibe.

## Live Site

This project is designed to run on [GitHub Pages](https://pages.github.com/). Enable GitHub Pages for the repository's `main` branch and open the generated site URL.

## Run Locally

Open `index.html` in any modern browser. No build tools, dependencies, or setup are required.

## Built With

- HTML
- CSS
- Vanilla JavaScript
